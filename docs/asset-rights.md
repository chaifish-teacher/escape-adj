# Asset attribution and licensing review

All PNG/JPEG source artwork: teacher-provided Twinkl “ESL Escape the Room: Adjectives of Appearance” PowerPoint and PDFs. Original files retain embedded Twinkl attribution. `public/assets/vocabulary/`, `castle/`, `monsters/` and the two main puzzle images are original embedded media, losslessly PNG-compressed; `characters/slide8-*` and `puzzles/slide10-*` are source-preserving slide crops. CSS lighting effects and oscillator sound/music are original application code. Adventurer uses source image9, not newly generated artwork.

Before public deployment:

- [ ] Teacher confirms the applicable Twinkl license and source download rights.
- [ ] Confirm permission to extract, adapt, display and redistribute these assets in a publicly accessible application (a classroom license does not automatically grant public redistribution).
- [ ] Review required credits, logos and attribution placement; add any publisher-required wording before publishing.
- [ ] Confirm GitHub repository visibility and prevent public upload of restricted originals or artwork without permission.
- [ ] If public asset rights cannot be obtained, restrict the deployment appropriately or commission approved artwork in a separate task. Do not silently substitute unrelated images.
- [ ] Review student name collection, consent and retention under school policy.

No public asset redistribution or deployment authorization is assumed. The current extracted assets are for teacher-provided local development and review.
