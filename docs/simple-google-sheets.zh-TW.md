# 最簡單的 Google Sheet 設定：登入與成績

這個版本只需要一張試算表、一份 GAS、一個部署網址。不需要密鑰，也不需要設定 Vercel 環境變數。請使用 **backend/SimpleRecords.gs**，不要使用進階版 backend/Code.gs，也不要把兩份 GAS 同時貼進同一個 Apps Script 專案。

## 1. 建立試算表並貼上 GAS

1. 建立一份新的 Google 試算表，例如「高塔英語學習紀錄」。
2. 在試算表選 **擴充功能 → Apps Script**。
3. 將預設 `Code.gs` 的內容全部刪除，貼入本 repository 的 **backend/SimpleRecords.gs** 完整內容，按儲存。
4. 上方函式下拉選單選 **setupRecords**，按 **執行**。依 Google 畫面以自己的帳號授權。
5. 回到試算表，會自動建立 **學生紀錄** 工作表和下面的第一列欄位。不必手動建立欄位或填試算表 ID。

| 欄  | 欄位     | 內容                                         |
| --- | -------- | -------------------------------------------- |
| A   | 紀錄ID   | 防止重複寫入，可隱藏                         |
| B   | 學生ID   | 分辨不同裝置的匿名玩家，可隱藏               |
| C   | 姓名     | 學生輸入的姓名                               |
| D   | 紀錄時間 | 台灣時間，自動填入                           |
| E   | 活動     | 登入／單字練習／聽力練習／拼字練習／密室挑戰 |
| F   | 分數     | 單字、聽力、拼字的答對題數；密室完成為 4     |
| G   | 總分     | 單字 8，聽力 6，拼字 6，密室 4               |
| H   | 答錯次數 | 該次活動的錯誤嘗試次數                       |
| I   | 挑戰秒數 | 密室實際完成耗時；其他活動空白               |

登入是一筆紀錄，每次完成活動也是一筆；登入列的分數空白。學生沒有練習的項目不會被補成零分。老師可用「資料 → 建立篩選器」依姓名與活動查閱，也能查看同一學生每次練習的變化。請保留原始欄位順序與工作表名稱。

## 2. 部署 GAS，取得網址

1. Apps Script 右上 **部署 → 新增部署**。
2. 齒輪／選取類型 → **網頁應用程式**。
3. **執行身分：我**。
4. **誰可以存取：任何人**（不只是「任何擁有 Google 帳號的人」，學生不需要登入 Google）。
5. 按 **部署**，複製「網頁應用程式」的網址。正確網址結尾是 `/exec`。

部署網址形式：`https://script.google.com/macros/s/你的部署ID/exec`。

## 3. 把網址放入網站

將部署網址貼回 Codex 對話，我會替你填入下列檔案並推送 GitHub：

```ts
// src/recording-config.ts
export const GOOGLE_SCRIPT_URL = "你的完整 /exec 部署網址";
```

這個網址不是密碼，不需要額外的 Sheet ID、API key 或 Vercel 設定。如果 GitHub 已連結 Vercel，自動建置完成後即可使用新版本；否則在 Vercel 重新部署最新版程式碼。此版本可直接從網站連 GAS，不需要 `/api/game` 代理。

## 4. 你會看到什麼

- 學生輸入姓名登入：試算表新增「登入」紀錄。
- 完成單字、聽力或拼字：新增該次分數紀錄。
- 完成密室：新增通過四關的 4/4、錯誤次數、實際耗時。
- 網站下方顯示待同步紀錄數或已同步；只有查到 GAS 寫入收據才會移除待同步項目。
- 網路中斷時暫存在同一瀏覽器，重新連線後重送；不要清除瀏覽器資料或關閉頁面，直到同步完成。
- 同一筆請求重送不會多出重複列。此版本記錄每次練習／挑戰，不採用伺服器正式排名規則。

第一次設定完，請自己登入並完成一個活動，在 Sheet 確認出現紀錄。尚未有部署網址時，網站仍能遊玩，但不會上傳紀錄。

日後如果修改 GAS 程式，選 **部署 → 管理部署 → 編輯 → 新版本 → 部署**，原 `/exec` 網址可保持不變。只按編輯器儲存不會更新網頁應用程式。

## 技術說明

採用普通 POST 寫入，並用只回傳是否寫入的 JSONP 收據避免 Apps Script 的跨網域讀取限制。POST 的 opaque 回應不會被當成已成功儲存；寫入收據確認之前，紀錄會留在裝置的佇列。讀取端不提供學生名單或成績。這是匿名課堂紀錄模式，姓名／裝置 ID 不等於經過驗證的真實學生身分，分數由遊戲傳送。
